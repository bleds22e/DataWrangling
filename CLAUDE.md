# DataWrangling course materials

Weekly R lessons and assignments for a data wrangling course. Code uses the tidyverse.

## Writing style

When writing or editing lessons and assignments, always mimic the existing style of the materials instead of imposing your own.

- Don't use bold text. The lessons use plain text; new terms are introduced with *italics* (e.g., *looping by index*).
- Write in a conversational, first-person voice that speaks to students directly ("Let's...", "I often...", "Remember...?").
- Point students to the assignment with the existing pattern:

  ```
  ### Let's Practice!

  | Work on Questions 1a and 1b in the Assignment.
  ```

- Comment code generously with `#` comments that explain each step.
- Match the formatting of the surrounding lesson (headings, bullet style, `-   ` list indentation from the visual editor) rather than adding new formatting conventions.
